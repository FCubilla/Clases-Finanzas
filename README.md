# FacuPadel

Aplicación para controlar clases, pagos, gastos y rendiciones de club.

## Uso

- Carga clases y pagos rápidamente desde el celular.
- Separa ingresos en efectivo y transferencia.
- Mantiene los datos localmente y permite sincronizar con Google Sheets si se configura.

## Configuración

Para la sincronización con Google Sheets, seguí la guía en [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md).
